The first start can take a while: LocalAI writes its configuration and downloads any preloaded
models before /readyz answers. Backends are downloaded the first time a model needs them.
{{- if not (include "local-ai.apiProtected" .) }}

WARNING: authentication is off. Anyone who can reach the service (any pod in the cluster) is an
  administrator, which includes running code in the pod (installing backends).
  Set apiKey.existingSecret or auth.enabled=true before exposing it.
{{- end }}
{{- if include "local-ai.authEnabled" . }}

The first account that signs up becomes an administrator, whatever auth.registrationMode says:
  create yours now, through the port-forward above, before exposing the service.
{{- if and .Values.auth.adminEmail (not .Values.auth.disableLocalAuth) }}
  WARNING: auth.adminEmail with local sign-up on: anyone who registers a local account with that
  email (emails aren't verified) becomes an administrator. Set auth.disableLocalAuth=true.
{{- end }}
{{- end }}
